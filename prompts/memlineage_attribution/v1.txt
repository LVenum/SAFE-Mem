The user message is a JSON object with two fields. "derived_entry" is a memory entry the agent wrote. "candidates" is the list of context items that were in front of the agent when it wrote that entry, each with an "id" and its "content".

For each candidate, score from 0 to 1 how much that candidate semantically influenced the content of derived_entry: 1 means the entry's content comes from that candidate, 0 means the candidate contributed nothing to it.

Reply with JSON only, in this form, one weight per candidate in the order given:
{"weights": [0.0, 1.0]}
